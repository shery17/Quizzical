# Quizzical
Trivia quiz app

Live link: https://quizzical1234.netlify.app/

## Tools/Languages used

Front-end: React, JavaScript, HTML, CSS
Back-end: Node.js, Vite

Public API used: https://opentdb.com/api_config.php

### Installation/Running steps

1. Ensure Node.js and NPM are installed on your computer.
2. Download this repository.
3. Unzip the archive of the downloaded repo and open the folder in VS code.
4. Open the terminal in VS Code
5. In the terminal run 'cd quiz-app'
5. Run 'npm install'
6. Run 'npm run dev
